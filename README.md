# ಕನ್ನಡವೇ ನಮ್ಮ ಉಸಿರು — Kannada Culture Hero

A single-page cultural hero section celebrating **Kannada (ಕನ್ನಡ)** pride and
Karnataka identity, with a looping **Karnataka flag** video as the background.

## Design
- **Primary color:** `#c62828` (red) — CTA button, accents.
- **Secondary color:** `#ffd700` (gold) — headline emphasis, labels, logo mark.
- Colors mirror the yellow/red Karnataka flag.

## Copy
- **Headline:** ನಮ್ಮ ನಡೆ ಕನ್ನಡದೆಡೆ, / ಕನ್ನಡವೇ ನಮ್ಮ ಉಸಿರು
- **Sub-heading:** ಕರ್ನಾಟಕದ ಭವ್ಯ ಸಂಸ್ಕೃತಿ, ನೆಲ, ಜಲ ಮತ್ತು ಭಾಷೆಯ ಉಳಿವಿಗಾಗಿ
  ನಿರಂತರ ಹೋರಾಟ. ನಮ್ಮ ಅಸ್ಮಿತೆಯನ್ನು ಉಳಿಸಿ ಬೆಳೆಸಲು ನಮ್ಮೊಂದಿಗೆ ಕೈಜೋಡಿಸಿ.

## Files
- `index.html` — the hero page. The hero copy, nav, CTA and slogan are all in Kannada.
- `assets/tailwind.css` — pre-built, minified Tailwind stylesheet (only the
  classes this page uses). Replaces the Tailwind CDN so the page needs **no
  external network**.
- `assets/fonts.css` + `assets/fonts/*.woff2` — self-hosted Noto Serif/Sans
  Kannada, Inter and Instrument Serif (via `@fontsource`). Replaces Google Fonts.
- `assets/karnataka-flag.mp4` — background video of the Karnataka flag
  (yellow/red bicolour) waving in the wind. Muted, autoplaying, looping. It sits
  under a dark gradient overlay so the foreground text stays legible.

## Notes
- **Self-contained / offline-ready:** no CDN or Google Fonts requests — the page
  renders fully styled even behind restrictive networks.
- The video is a full-bleed `<video autoplay muted loop playsinline>` behind a
  `.hero-overlay` darkening gradient.
- To view: open `index.html` in any modern browser.

## Rebuilding `assets/tailwind.css`
The stylesheet is generated by scanning `index.html` for Tailwind classes:

```
npm install tailwindcss@3 @tailwindcss/forms
npx tailwindcss -c tailwind.config.js -i input.css -o assets/tailwind.css --minify
```

where `tailwind.config.js` sets `content: ['index.html']` and the brand theme
(`brand.red #c62828`, `brand.gold #ffd700`, `brand.dark #0A0A0A`, and the
serif/sans Kannada font families).
